## 🚀 Featured Projects

### 🏠 [서집사](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN04-FINAL-1Team)

20~30대 청년의 부동산 접근성을 높이기 위한
**AI 기반 부동산 매물 검색 및 추천 챗봇 서비스**입니다.

사용자의 자연어 질문을 분석해 원하는 조건에 맞는 부동산 매물을 검색하고,
RAG를 활용해 부동산 관련 정보를 제공하도록 구현했습니다.

#### 담당 역할

* LangChain과 LangGraph 기반 AI 대화 흐름 구성
* 자연어 질문을 SQL Query로 변환하는 기능 개발
* Chroma Vector Database 구축
* 부동산 관련 문서 검색을 위한 RAG 파이프라인 구성
* LLM과 검색 시스템 연동
* AI 응답 및 프롬프트 성능 개선

#### 주요 기술

`Python` `LangChain` `LangGraph` `OpenAI API` `RAG`
`Chroma` `Django` `React` `PostgreSQL` `Docker` `AWS`

### 📸 [CapShop](https://github.com/SyncShopper/syncshopper)

유튜브 영상 속 상품을 캡처하면 AI가 상품을 분석하고,
비슷한 쇼핑 상품을 찾아 추천해 주는 서비스입니다.

사용자가 직접 상품명이나 브랜드를 알지 못하더라도
이미지와 OCR 정보를 바탕으로 상품 특징을 추출해 유사 상품을 검색합니다.

#### 담당 역할

* 프로젝트 팀장
* Spring Boot 기반 백엔드 API 개발
* Chrome Extension 화면 캡처 기능 개발
* 캡처 이미지와 백엔드 서버 연동
* FastAPI 기반 AI 분석 서버 개발
* LangGraph 기반 상품 검색 파이프라인 구성
* Gemini API와 네이버 쇼핑 검색 API 연동
* 텍스트 필터링 및 이미지 유사도 기반 상품 리랭킹

#### 주요 기술

`Java` `Spring Boot` `Spring Security` `MyBatis` `JWT`
`Python` `FastAPI` `LangGraph` `Gemini API` `Scikit-learn`
`Vue 3` `Vite` `Chrome Extension` `MySQL` `Redis`
